# 账单有数：独立网页

默认使用本机存储的个人静态账单提醒工具，可选独立的邮箱自动读取后台。页面代码公开，初始账单以 AES-256-GCM 加密后发布；访问口令不在仓库中。PBKDF2-SHA256 使用独立随机盐和 600000 次迭代。口令只在浏览器本机参与解密，不提交到服务器。

解锁后，账单及修改记录以普通本机浏览器数据保存；不提供设备本身被他人控制时的保护。请只在自己的设备使用并定期导出备份。网页解锁没有口令找回，启用可选后台后另以个人连接码读取云端邮件识别结果。任何持有解锁口令的人都能解密初始账单，请妥善保管。

支持九家银行选项、人工账单核对、TXT/HTML/EML 导入、JSON 备份恢复、还款日/账单金额/最低还款展示及 3/1/0 天日历提醒。可选个人邮箱自动读取后台：必须另行部署并启用每日定时任务，单独更新静态网页不能实现定时读邮件。网页通知仅在网页运行时检查，关闭网页后的提醒需要导入手机日历并确认通知设置。

自动读取入口在“设置 → 每期账单自动读取”。连接码保存在当前浏览器，只用于读取私人后台的结构化账单；QQ 授权码仅在云函数私有环境变量配置，不写入网页代码或浏览器。后台每天检查最近 120 天的账单邮件，自动入账要求人民币字段齐全、发件域名与银行匹配、同卡同期结果无冲突；超限、外币、缺失字段均提示核对。原邮件正文不入库。后台成功检查不保证全部银行模板均已覆盖。

本机同卡同一期的账单保持原样，包括所有还款记录；新邮件金额或日期发生变化时提示核对。新账期单独新增为待还，不继承上一期的还款。此后台不保存用户手记的还款，不提供跨设备还款同步；手机换入口时仍需导入最新备份。断开此设备不会停掉后台任务，停止持续读取须在云函数关闭 AUTO_SYNC_ENABLED 或禁用定时触发器。

主流现代安卓/苹果浏览器可访问。网页是否能打开、通知是否生效需要在实际网络和设备验证；没有所有手机或所有网络可用的保证。

部署：把本目录静态文件发布到 HTTPS 静态托管的同一目录；无需 ChatGPT、GitHub 登录或任何 API 密钥即可使用网页。GitHub 账号仅用于维护发布代码。不得把自己的账单 JSON、邮件、授权码或登录会话加入本公开仓库。

首次联网访问后缓存公开页面文件，个人账单保存在 localStorage。更换设备、域名、浏览器或清除存储前先导出备份。更换域名会改变存储位置，原数据不会自动迁移。已导入的日历事件不会随网页还款标记自动取消。

本站未接入广告、统计脚本或第三方字体。静态托管服务仍可能记录访问 IP 等网络日志。
