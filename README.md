# 账单有数：独立网页

无账户登录、无后台接口的个人静态账单提醒工具。页面代码公开，初始账单以 AES-256-GCM 加密后发布；访问口令不在仓库中。PBKDF2-SHA256 使用独立随机盐和 600000 次迭代。口令只在浏览器本机参与解密，不提交到服务器。

解锁后，账单及修改记录以普通本机浏览器数据保存；不提供设备本身被他人控制时的保护。请只在自己的设备使用并定期导出备份。后端没有身份认证、口令找回或银行连接服务。任何持有口令的人都能解密初始账单，请妥善保管。

支持九家银行选项、人工账单核对、TXT/HTML/EML 导入、JSON 备份恢复、还款日/账单金额/最低还款展示及 3/1/0 天日历提醒。没有自动读取邮箱和后台推送。网页通知仅在网页运行时检查，关闭网页后的提醒需要导入手机日历并确认通知设置。

主流现代安卓/苹果浏览器可访问。网页是否能打开、通知是否生效需要在实际网络和设备验证；没有所有手机或所有网络可用的保证。

部署：把本目录静态文件发布到 HTTPS 静态托管的同一目录；无需 ChatGPT、GitHub 登录或任何 API 密钥即可使用网页。GitHub 账号仅用于维护发布代码。不得把自己的账单 JSON、邮件、授权码或登录会话加入本公开仓库。

首次联网访问后缓存公开页面文件，个人账单保存在 localStorage。更换设备、域名、浏览器或清除存储前先导出备份。更换域名会改变存储位置，原数据不会自动迁移。已导入的日历事件不会随网页还款标记自动取消。

本站未接入广告、统计脚本或第三方字体。静态托管服务仍可能记录访问 IP 等网络日志。
